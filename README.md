# Desafio de Cadastro

Projeto simples de formulário de cadastro de usuário feito com HTML, CSS e JavaScript. O formulário valida os dados antes de exibir uma confirmação de cadastro.

## Funcionalidades

- Verifica se nome, e-mail e senha foram preenchidos.
- Faz uma validação básica do e-mail, verificando se contém `@`.
- Exige uma senha com pelo menos 6 caracteres.
- Exibe mensagens de sucesso ou erro no formulário.

## Como executar

1. Baixe ou clone este projeto.
2. Abra o arquivo `index.html` em um navegador.
3. Preencha os campos e clique em **Cadastrar**.

Não é necessário instalar dependências ou iniciar um servidor.

## Arquivos

- `index.html`: estrutura do formulário.
- `style.css`: estilos da página e das mensagens.
- `script.js`: validação dos campos e exibição do feedback.

## Observação

A validação do e-mail é simples e serve apenas para este exercício. O formulário não envia os dados a um servidor; ele apenas valida os campos e mostra o resultado na página.
